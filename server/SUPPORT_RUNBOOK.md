# Support and Moderation Runbook

Users create private tickets at `/support` and moderation appeals at `/appeals`. Moderators use `/admin/cases` to assign an owner and resolve cases. When possible, an appeal should be reviewed by someone other than the original decision-maker.

For incidents, record the affected server, approximate time, request or submission ID, expected result, actual result, and reproducible steps. Escalate security or privacy reports to a bot owner immediately. Do not request credentials from users.

Public operational communication belongs on `/status`; release changes belong in `RELEASE.md`. Known limitations should be documented before launch rather than hidden in support replies.
