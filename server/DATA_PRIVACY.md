# Data Privacy Operations

Signed-in users can download a JSON export or request deletion from `/account/privacy`. Deletion requests require administrative verification to prevent impersonation and accidental destructive action.

Retention settings cover audit entries, rate-limit records, pending submissions, and local originals. Operators should document jurisdiction-specific retention requirements, process verified deletion requests promptly, and preserve only narrowly required security/audit records.

Never place passwords, Discord bot tokens, SMTP credentials, webhook secrets, or OAuth secrets in support tickets, exports, logs, or screenshots.
